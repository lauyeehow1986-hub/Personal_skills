`PKG` does **the one thing it is for**, so you can **the outcome users care about**. One paragraph, two or three sentences, bold the phrases a skimmer should catch.

## Installation

Install the development version from GitHub:

```r
# install.packages("remotes")
remotes::install_github("OWNER/PKG")
```

## Key Features

- **Feature Name In Title Case**: One sentence on what it does for the user, naming the function (`pkg_fun()`).
- **Grouped Feature**:
  - Sub-point with its function (`pkg_other()`).
  - Sub-point with its function (`pkg_third()`).
- **Another Feature**: One sentence.

## Quick Start

```r
library(PKG)

# 1. The first thing a new user does
result <- pkg_fun(example_data)

# 2. The next step
pkg_other(result)

# 3. Getting something out (a file, a plot, a table)
pkg_third(result, file = "output.html")
```

One closing line: where to go next (reference pages, a vignette) or a scope disclaimer.
