# Skills index (for any coding agent)

Before starting a task, check whether one of these skills matches it. If one does, read its
`SKILL.md` in full and follow it. Paths are relative to this repository, so run its scripts from
the skill's folder or pass their full path.

- `skills/building-r-package-sites/SKILL.md`: use when creating, redesigning or publishing the
  GitHub Pages / pkgdown website or README home page of an R package, or when the site looks bad on
  phones, publishes agent notes (CLAUDE.md, AGENTS.md, MEMORY.md), shows a stale logo or deploys
  inconsistently.
- `skills/making-hex-logos-from-ai-images/SKILL.md`: use when a user supplies AI-generated or raster
  hex-sticker artwork and wants a package logo, README logo, favicon set or GitHub social preview card.
- `skills/effort-harness-router/SKILL.md`: use when deciding which coding harness, model tier or
  reasoning effort to use for a task, or how to cut token cost and latency on a coding task.
